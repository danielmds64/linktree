# Minha Linktree

Página pessoal estilo linktree, feita do zero usando apenas HTML, CSS e JavaScript puro (sem frameworks ou bibliotecas). Esse projeto foi solicitado como atividade do Módulo 3 - Fundamentos de Desenvolvimento Web -- do Curso de Capacitação em Desenvolvimento Full-Stack pelo ITEAM.

Link da página: [danielmds64.github.io/linktree/](https://danielmds64.github.io/linktree/)

## Funcionalidades

- Layout responsivo
- Lista de links personalizáveis
- Estilização própria, sem uso de templates prontos

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript (Vanilla)
